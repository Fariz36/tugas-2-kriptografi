Dokumentasi API JAV-128
===========================

API ini digunakan untuk memanggil JAV-128 dari Python 3.11 atau lebih baru.
JAV-128 adalah cipher eksperimental untuk pembelajaran. Hasil pengujian
statistik belum membuktikan keamanannya untuk penggunaan produksi.

Referensi fungsi diambil langsung dari docstring kode melalui Sphinx autodoc.
Nama parameter dan anotasi tipe mengikuti kode yang diimpor saat build.
